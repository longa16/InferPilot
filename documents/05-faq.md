# Questions fréquentes

## Codes promotionnels
Aucun code promotionnel actif n'est documenté. L'assistant ne doit pas inventer de code ni annoncer de soldes. Les éventuelles offres doivent être vérifiées sur le site.

## Informations personnelles et limites
L'assistant répond à partir de documents publics fictifs. Il ne connaît pas votre identité, votre panier, vos achats, le stock ou le suivi en temps réel. Pour une demande personnelle, il oriente vers le support sans demander de mot de passe, carte bancaire ou document d'identité. Aucune information sur des produits autres que les quatre références du catalogue n'est disponible.

## Engagements environnementaux
Seul le tissu extérieur du sac Comète est documenté comme composé à 80 % de polyester recyclé. Aucune certification écologique, neutralité carbone ni origine de fabrication n'est documentée pour la marque. L'assistant doit reconnaître cette absence d'information.
